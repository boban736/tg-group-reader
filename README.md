# tg-group-reader

Раз в час читает Telegram-группу (от твоего аккаунта, через Telethon), отдаёт новые сообщения вместе с фото и текстом файлов в GPT и пишет полезное в дневную заметку Obsidian. О срочном пишет в «Избранное».

## Установка (macOS)

1. Получи `api_id`/`api_hash` на https://my.telegram.org → API development tools.
2. `./scripts/install.sh` — создаст `.env`; заполни его и запусти ещё раз. При первом запуске Telegram спросит номер и код, сессия сохранится в `tg.session` (**не отдавай этот файл никому — это доступ к аккаунту**).
3. Дальше launchd запускает `reader.py` раз в час. Если Mac спал, при пробуждении скрипт подберёт всё пропущенное: он читает с последнего обработанного сообщения.

## Что получается в vault

- `Универ/Дайджест/2026-10-07.md` — frontmatter (date, tags), блоки по часам, разбивка по категориям. Предметы стоят как `[[Математическая логика]]`, у каждой записи есть ссылка на исходное сообщение.
- `Универ/Дайджест/files/` — фото и файлы, на которые ссылаются полезные записи; в заметку они встроены через `![[...]]`.

## Настройка

- Что считать полезным: `prompts/system.md`.
- Пути, теги, лимиты: `.env` (см. `.env.example`).
- Ручной запуск: `.venv/bin/python reader.py`; лог: `reader.log`.
- Начать заново: удалить `state.json`, тогда возьмутся последние `FIRST_RUN_HOURS` часов.
